### About Me

- AI 서비스를 이해하고 안정적으로 배포·운영할 수 있는 **인프라 엔지니어**를 목표로 하고 있습니다.
- 현재 AI 모델 개발 인턴으로 **한국수어 수형 인식 프로젝트**를 진행하고 있습니다.
- FastAPI 기반 백엔드와 Docker 환경을 AWS ECS Fargate, RDS, ElastiCache, S3 등의 관리형 서비스로 확장한 경험이 있습니다.
- 기능 구현뿐 아니라 요구사항, 제약조건, 검증 방법과 운영 환경을 함께 고려합니다.
- AI가 만든 결과를 그대로 사용하는 것이 아니라 설계 결정과 트레이드오프를 제 언어로 설명할 수 있는 엔지니어를 지향합니다.
